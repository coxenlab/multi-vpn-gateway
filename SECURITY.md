# 安全说明 / Security

macOS 应用会安装一个以 root 运行的助手程序，并保存各家 VPN 的登录凭据，所以安全问题请**私下报告**，不要开公开 Issue。

- 报告入口：[Security → Report a vulnerability](https://github.com/coxenlab/multi-vpn-gateway/security/advisories/new)
- 请写明版本、影响范围和复现步骤；附件里的客户名、内网地址、账号请先打码。
- 只维护最新发布版本。

The macOS app installs a privileged helper running as root and stores VPN
credentials, so please report security issues **privately** through
[GitHub private vulnerability reporting](https://github.com/coxenlab/multi-vpn-gateway/security/advisories/new),
not in a public issue. Only the latest release is maintained.
